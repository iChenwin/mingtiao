# 明跳 MingTiao

一个权限与行为透明、离线工作的 Android 无障碍广告跳过工具。Android 8.0+，Java 17，原生界面，运行时无第三方依赖。

**当前为 0.1.0 初版，尚未完成真机验收，不是李跳跳的完整复刻。** 参考 APK 的静态分析、加固限制和功能差距见 [功能对照](docs/STATIC_ANALYSIS.md)。独立编写源码，不分发原应用代码、资源、签名或规则库。

## 已实现

- 开屏「跳过 / 跳过广告 / Skip ad」及倒计时变体识别。
- 逐应用授权、应用搜索、总开关和默认启用的预览模式。
- 自定义文字、内容描述、资源 ID、包含匹配；可限定 Activity。
- 开屏及弹窗规则；控件点击、归一化坐标手势、返回动作。
- 本地 JSON 规则编辑、删除、启停、文件导入/导出。
- 本地操作次数、最近 100 条操作元数据、一键清空。
- 事件驱动 + 400ms 重查、时间窗口、频率限制和每会话操作上限。

## 使用

1. 从 [测试版 Releases](https://github.com/iChenwin/mingtiao/releases) 下载 APK，或自行构建 / 从 Actions 的 `debug-apk` artifact 下载。测试包使用调试签名，不作为稳定签名发行。
2. 在应用中阅读权限说明，手动进入 Android 无障碍设置启用「明跳」。
3. 在「应用」中只启用你需要跳广告的应用；开启首页总开关。
4. 保持预览模式，重新进入目标应用，检查「记录」中的规则命中。
5. 确认后关闭预览，再次进入应用验证。任何误操作都可在首页立即暂停或在系统设置关闭服务。
6. 对无法识别的广告，在「规则」中添加完整包名、触发条件和目标。参考 [示例规则](docs/rules.example.json)。

系统侧载限制需由用户自己处理。应用不会自动授予权限、确认安装、自动接受权限提示或操作系统设置。

## 权限与隐私

Manifest 不申请 INTERNET、存储、QUERY_ALL_PACKAGES、悬浮窗、Root、设备管理或 VPN 权限。文件导入/导出使用系统文档选择器。备份关闭，无广告、统计 SDK、远程规则或脚本执行。开源代码不能限制 Android 授予的无障碍能力，安装包需来自可信构建。

无障碍能读取控件和执行点击，因此无法承诺“只拥有广告访问权限”。明跳只在已启用应用中取当前根节点；其他包的窗口事件仅用于判断前台切换。只遍历有限节点，不读取输入框和密码节点内容、不截图、不保存界面树或屏幕文字。完整权限边界见 [SECURITY.md](SECURITY.md)。

默认：暂停、预览开启、无授权应用、无自定义规则。内置识别只在进入应用后 8 秒内工作。每次前台会话最多尝试 3 次操作，间隔至少 900ms；自定义开屏规则支持 1–15 秒，弹窗规则可持续至退出前台或达到会话上限。预览命中会去重。返回和坐标规则必须存在明确的可见触发条件。规则可以误点，导入前请审阅。

## 规则格式

根对象为 `{"version":1,"rules":[...]}`；每条需要 `name`、`package`、动作 `action`（click / tap / back），默认启用。click 需要 `target`；tap / back 及 popup=true 需要非空 `trigger`。建议每条均填写准确的触发条件。

选择器：`text:跳过` 精确匹配文字或内容描述；`id:com.example.app:id/skip` 精确资源 ID；`contains:关闭广告` 显式包含匹配。无前缀时按精确文字匹配。坐标 x/y 为当前根窗口范围的比例，旋转和布局变化可能导致误点。Activity 条件需填写完整类名。

文件上限 256 KiB、规则上限 200 条。导入完整校验后确认替换，自动暂停并恢复预览，不自动授权应用。不兼容李跳跳 AllRules.json；不能凭包名哈希可靠恢复规则目标。

## 构建与验证

环境：JDK 17、Android SDK Platform 36 / Build Tools 35.0.0。

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
# 测试包：app/build/outputs/apk/debug/app-debug.apk
# 未签名发布构建：
./gradlew assembleRelease
```

Android Studio 打开根目录即可导入。`local.properties` 可配置本机 `sdk.dir`。Gradle Wrapper 8.11.1、AGP 8.10.1。[验收清单](docs/TESTING.md) 区分自动检查与必须完成的真机检查。

已知限制：没有真机适配数据；无障碍不可见的 Canvas / WebView 广告不保证可识别；事件类名受应用实现影响，Activity 限定需实测；前台会话按窗口事件判断，某些厂商/应用切换可能导致漏识别或新会话；系统可能中止服务；最多 3 次动作不适合长时间复杂弹窗链。不自动推断任意“关闭”按钮，不承诺所有广告都可跳过。
