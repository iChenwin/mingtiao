# vivo X200 Pro mini · OriginOS 6 · Android 16

用户提供的目标设备；本项目 compileSdk / targetSdk 36。**尚未在该设备上实测，以下为操作与验收建议，不是兼容认证。**

## 初次启用

1. 安装自己构建的测试 APK 或核对 CI 产物来源后安装。Android 16 不需要 Root。
2. 打开明跳，阅读权限说明，再通过应用内按钮进入系统「无障碍」设置。系统名称可能是「辅助功能」或「已下载的应用」，以手机实际页面为准。
3. 如系统提示该侧载应用受限制，只在你确认源码和 APK 来源后，使用系统提供的手动授权流程。不要使用自动化工具代点系统安全提示。
4. 明跳首页确认服务已启用，在「应用」开启一个普通测试应用，保持预览、开启总开关，重新打开测试应用。
5. 记录中出现对应命中后，关闭预览，再测试实际广告跳过。

## 服务被停止时

先在明跳首页确认服务状态和总开关，再检查系统设置。若确实遇到后台终止，可在设置搜索「自启动」「后台耗电管理」或「后台高耗电」，只对明跳按需配置。vivo 官方客服提供过自启动与后台耗电管理的排查方法，但该文档较早，不能据此保证 OriginOS 6 的菜单路径一致：
https://kefu.vivo.com.cn/robot/imgmsgData/2616a9cd7cd64a5083a264d16e5767da/index_1.html

不需要打开锁屏显示、后台弹出界面、设备管理或悬浮窗。明跳没有接管系统设置、自动保活或自动重新授权的逻辑。

## 此设备必须补齐的验收

- [ ] 首页、应用列表、规则长表单在状态栏/手势导航/键盘下没有遮挡。
- [ ] 屏幕熄灭后无操作，解锁后能正确识别新的前台会话。
- [ ] 预览无实际点击；关闭预览后只有授权应用执行操作。
- [ ] 已授权应用 → 系统权限弹窗/安装界面/通知栏，均不操作系统界面。
- [ ] 从广告应用切走后，无旧规则手势执行到其他应用。
- [ ] 3 次上限、900ms 间隔、8 秒内置检测窗有效。
- [ ] 自定义坐标在竖屏/横屏和不同显示缩放下不会误点。
- [ ] 暂停后不再操作；在系统关闭服务后不再接收事件。
- [ ] 待机 30 分钟、重启、系统省电模式后的服务行为已记录。
- [ ] 2–3 个目标应用的版本、实际按钮标签与规则已记录。

Android 16 行为变化参考官方文档：https://developer.android.com/about/versions/16/behavior-changes-all 。仅将 SDK 版本设为 36 不能替代以上实机测试。
