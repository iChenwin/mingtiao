- 应用包名 `hello.litiaotiao.app`。
- Manifest 声明查询全部应用、前台服务、通知权限；未发现 INTERNET 声明。这一事实不能证明完整运行时行为安全，也不能证明存在滥用。

- APK 含 Tencent StubShell / wrapper 加固入口，静态 DEX 主要为加载器；业务逻辑未以可直接解析的普通类完整呈现。**本次静态分析不能还原其全部业务实现，也没有完成运行时脱壳和动态行为验证。**

- 仓库的 AllRules.json 使用包名哈希键和内嵌 JSON；样例含弹窗触发/动作和返回动作。哈希不能无歧义反推包名，缺少原实现时不能保证兼容。
